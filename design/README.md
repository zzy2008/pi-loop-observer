## 模拟场景

用户请求“找出测试失败的原因”。第一轮模型运行 0–4.2 秒；read 在 4.2–6.0 秒执行，bash 在 4.2–10.4 秒执行并失败；第二轮模型在 10.4–15.2 秒处理结果并输出解释。默认位于 12.4 秒，第二轮正在输出。

工具失败不代表整个问题失败。节点详情中的输入输出全部为人工编写的示例。当前回放时间范围包含整个已知样例，用于设计评审；真实运行的界面不能提前知道结束时间。

桌面采用图形、时间轴、详情联动。窄屏将流程改为纵向，点击节点打开底部详情面板。选中尚未发生的调用时，详情显示无记录；调用未结束时不展示最终结果。

“折叠第一轮”只对完成的第一轮生效。“回到模拟实时”恢复到预设快照；效果稿没有实际连接、暂停或控制 agent 的能力。缩放、跨问题切换、完整历史库和重连将在真实实现中完成，效果稿不提供这些入口。

## 视觉规范

使用浅色中性背景与紫色模型／活动标识，工具使用蓝灰色，失败使用柔和红色。颜色与文字状态一起表达含义。节点保持稳定位置；边表示调用及结果关系，时间条表示实际时间。时间条共用尺度，不以耗时排行替代时序。
