# UI 样式约定

更新：2026-10-18。用于维护 Observer 界面的一致性；字体和尺寸按信息用途分级，同类元素使用相同规则。

## 字体层级

| 用途       | 字号           | 字重                           | 示例                                     |
| ---------- | -------------- | ------------------------------ | ---------------------------------------- |
| 产品标识   | 16px           | 600                            | Header 品牌                              |
| 面板标题   | 14px           | 600                            | 时间轴、调用详情                         |
| 正文与操作 | 13px           | 正文400、控件500、名称/分组600 | 按钮、选择器、搜索框、调用名称、问题摘要 |
| 辅助信息   | 12px           | 400                            | 状态、时间戳、坐标刻度、类型标签         |
| 代码正文   | 12px，等宽字体 | 400                            | JSON、命令、工具输入输出                 |

使用系统字体与明确的中文回退，不依赖外部字体服务。正文、表单、React Flow 和 SVG 继承同一字体族；代码详情使用独立的等宽字体。窄屏维持字号层级，通过换行、折叠和局部滚动适配。

## 尺寸与交互

- 操作控件统一高度：桌面32px，手机36px。Graph调用节点保留90px高度；Question是自适应大容器，每个Turn独立一行，调用横向间隔56px；Turn行间距12px、Question外间距24px。容器嵌套表达归属，箭头表达已记录关系。
- 圆角按组件类型统一：控件6px、图节点8px、面板10px。
- 使用2/4/8/12/16px间距规则；详情与时间轴采用一致的内容留白。
- 按钮、选择器与搜索框使用相同边框、字体和焦点轮廓。选中状态使用主题强调色，悬浮与禁用状态全局统一。
- 时间值使用等宽数字排布；数值的单位与已实现计时规则保持一致。

## 配色与文件职责

默认跟随系统主题，保留手动深色和浅色选择。使用中性灰蓝背景、蓝色模型调用、绿色工具调用、红色失败状态；主题色通过语义变量维护，禁止在组件中分别硬编码背景与文字颜色。

基础样式定义字体、文字层级和通用控件；主题文件维护语义颜色；紧凑布局文件管理导航与响应式排列；图样式仅管理节点内部结构和画布工具。删除旧组件残留和重复覆盖规则。

SVG 时间轴的画布单位与实际显示像素保持一致，坐标轴文字至少12px，调用与Turn文字13px。改变浏览器宽度时调整绘图范围，维持文字大小与当前问题计时含义。

具体文件：`web/src/tokens.css` 定义统一尺寸，`theme.css` 定义颜色，`style.css` 定义公共组件，`compact.css` 定义响应式布局，`graph-v2.css` 定义图节点。新增组件优先使用这些变量，避免独立添加相同用途的字号。

## 布局主次（2026-10-18）

页面依次为固定产品导航、会话上下文、常用筛选、可视化工作区和时间回放。默认执行轨迹将层级行和耗时条同屏展示，可切换调用图与时间轴，工作区占满可用宽度。轨迹行桌面34px、手机40px；每问摘要固定为耗时、轮次、模型调用和工具调用四项。详情按需展开，桌面在旁栏，手机轨迹详情位于轨迹下方；图谱和时间轴保留原移动详情面板。问题选择和搜索常驻，历史分支、轮次和调用跳转归入可折叠筛选区。新增操作优先放入对应区域，避免再增加独立常驻工具行。

`trace-view.css` 管理紧凑瀑布图。默认跟随最新问题，明确选择历史问题后保持固定；选中调用只滚动轨迹容器，不随实时刷新反复抢占滚动。缺失时序显示未记录，不补造等待或流式阶段。

## Graph 节点类型（2026-10-18）

类型使用固定图标、文字和样式：Question为紫色气泡/浅染底/14px圆角，Turn为灰蓝叠层/虚线框/5px圆角，LLM为蓝色芯片/左侧色条/8px圆角，Tool为绿色扳手/顶部色条/5px圆角。节点尺寸、字体保持一致。虚线框表示Turn类型，绿色表示工具类型；运行、失败、完成用独立状态图标与文字，不能覆盖类型色。选中外轮廓与类型边框分开。SVG图标不单独获得焦点，读屏名称包含可见类型及调用状态。

详细依据与主题色对比度见 [节点视觉调研](implementation/graph-node-visual-research.md)。

## 分组与图标（2026-10-19）

Question和Turn以嵌套容器表达，Turn容器使用低对比实线边框，替代独立Turn卡片的虚线。Question标题区限制最大宽度，手机使用三角折叠按钮。调用类型图标与状态编码沿用前述约定。Header使用本地Pi/GitHub/文档SVG图标；320px窄屏外链保留图标、可访问名称和title，避免文字挤出屏幕。favicon与实际深浅主题同步。

Graph、Trace和Timeline在已有问题/轮次容器内显示完整类型词，例如Turn 2、Call 1（中文：轮次2、调用1），省略重复父级编号；总览保留所需上下文，搜索、悬浮提示和详情保留稳定完整编号。时间条12px高、圆角、起点、末端耗时；模型蓝色、工具绿色、失败附红色与叉号。运行态动效遵循下述时间条规则，不能伪造百分比或等待/流式阶段。详细设计见 [分组图方案](implementation/grouped-graph-plan.md)。

## 时间条动效（2026-10-19）

`web/src/motion.css` 统一维护 Trace 与 Timeline 动效。时间刻度与条形位置/宽度必须在同一帧更新，可见耗时文字按下述低频规则显示，不对几何坐标单独做CSS过渡；只有流光、状态圆点与轮廓可动画。时间回放根据事件时间推进，两个事件之间持续更新观测耗时。动画不改变原始事件、耗时或阶段语义，也不表示完成百分比。

- Trace运行条使用1.6s低强度流光、末端亮点与状态圆点；Timeline运行条使用同周期流动轮廓和末端亮点。类型色继续使用模型蓝、工具绿。
- 暂停回放、拖动游标或实时连接中断时冻结活动动效；恢复播放或连接后继续。连接中断不改变既有耗时估算规则。完成调用移除运行效果，保留静态耗时条。
- 系统启用`prefers-reduced-motion: reduce`时关闭过渡和动画，保留静态状态文字与标记。
- 流光和状态提示使用装饰性CSS动画，与回放时间更新分离。桌面、390px和320px浏览器验证覆盖实时流动、回放恢复、暂停冻结、完成清理及减少动态效果；同时回归暂停期间断线恢复。共6项通过，类型检查和生产构建通过。

时间条旁的耗时使用观测终点减观测起点，与条形在观测时钟上的宽度一致。Pi SDK执行耗时单独标注在悬浮提示和详情中，禁止把SDK耗时作为观测条形的无标签数值。修复及逐帧回归依据见[时间条比例修复](implementation/timebar-timing-fix.md)。

## 时间回放（2026-10-19）

播放使用记录中的单调时钟间隔，1×与原始经过时间一致，0.5×和2×同比例变速。位置滑块按毫秒定位，显示当前位置/总时长；阶段按钮继续用于事件跳转。暂停冻结当前位置，恢复或中途变速不重置事件间已播放的时间。当前问题在实时模式点击播放时从该问题的输入事件开始；播放到记录末尾自动停止。

回放通过requestAnimationFrame随显示帧刷新观测时间，依据浏览器单调时钟实际经过时间计算，避免定时器调度延迟积累；仅跨过事件边界时更新可见事实，不提前显示未来调用或输出。同一时间戳事件一起生效；跨采集时钟使用墙上时钟间隔并标为近似，倒退间隔按零处理，保留问题内等待，跳过问题间空闲。

历史回放以当前问题的完整已记录范围固定时间轴；实时轴按1/2/5档位扩展。可见耗时文字与回放位置每500ms最多更新一次，播放中采用较粗精度；暂停和调用完成时立即显示精确值。条形保持动画帧刷新，不能为降低文字刷新而降低条形帧率。底部明确显示“问题回放”或“全部问题 · 跳过空闲”。
