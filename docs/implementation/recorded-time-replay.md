# 按记录时间回放

日期：2026-10-19。

## 问题与复现

原实现每`600 / speed`毫秒跳到下一个阶段，忽略事件之间真实经过的时间。可控浏览器时钟测试在1×播放500ms后，预期30ms开始的调用显示约470ms耗时，实际调用尚未出现。先运行失败测试再替换调度逻辑。

## 实现

- `replay-clock.ts`构建事件累计毫秒位置，同一采集时钟优先使用monoMs，不受墙上时钟校准影响。跨时钟以wallMs间隔衔接并标为近似；异常倒退间隔归零。问题内部真实等待完整保留；问题之间的空闲不计入执行回放。
- `useTimedReplay.ts`管理播放、暂停、拖动、倍率与末尾停止。以performance.now的实际经过时间推进，requestAnimationFrame负责显示帧调度。变速前结算旧倍率的已过时间，不丢弃事件间进度。
- 两个事件之间只推进观测时间，不生成新事实；跨过时间点后才选择对应的事件前缀，同时间戳记录批量生效。SSE可继续接收，暂停前缀不被覆盖。
- `ObserverPage.tsx`用同一回放时间投影Trace、Graph和Timeline。滑块改为时间位置；显示当前位置与总时长。上/下一阶段仍按事件跳转，当前问题从输入开始播放，末尾停止后再次播放从记录开头开始。
- 时钟域切换只能以墙上时钟估算间隔，UI明确显示近似时序；导入记录没有可计时实时事件时不启用播放。

## 验证

可控浏览器时钟覆盖：1×500ms、暂停2秒、2×200ms、中途切换0.5×、精确到调用结束、拖动到1500ms并保持暂停、继续播放、末尾停止和回到实时。单元测试覆盖单调时钟优先、空闲间隔、跨时钟/时间回退、相同时间戳和空记录。

命令：`pnpm exec playwright test -g 'replay follows recorded'`；`pnpm exec vitest run test/unit/replay-clock.test.ts`。

验证结果：34项相关单元测试、36项完整浏览器回归通过；最终调度细化后，桌面/390px/320px的9项计时与暂停/动效回归再次通过（包含延迟900ms仅触发一次回调的追赶测试）。类型检查、生产构建与`git diff --check`通过。

## 平滑度与图标控制补充

旧50ms刷新在480ms/30个模拟显示帧中仅呈现10个不同进度，造成约20fps的阶梯感。改用requestAnimationFrame，继续按performance.now实际经过时间计算；暂停或到末尾时取消帧循环，恢复时重新锚定，浏览器延迟不累积成时间漂移。刻度、条形和数值同一帧更新，不重新加入几何CSS过渡。

上一阶段、播放/暂停、下一阶段改为本地SVG图标，保留中英文aria-label及title、原生键盘操作。使用统一32px桌面/36px移动按钮与18px图标。浏览器测试直接检查可见条形宽度与播放游标在30个显示帧内持续变化，同时验证按钮可访问名称。

帧同步改动验证：桌面、390px、320px共18项浏览器回归通过；30个模拟显示帧中，播放游标至少更新25次、可见条形几何至少更新24次。时间倍率、暂停/恢复、延迟追赶、坐标比例与减少动态效果均通过。桌面及移动端图标截图已人工检查，类型检查和生产构建通过。

## 问题范围与数字稳定性修复

真实记录中，最后问题于10月4日完成，capture.stopped在10月13日才出现。旧回放把全部采集事件连起来，导致总时长216.58小时。现以input.applied到run.settled构建执行窗口，按问题筛选匹配窗口；全部问题串接各执行窗口并跳过问题间空闲。采集停止等维护事件不扩大执行时长。档案/绑定事实保留在事件前缀中，但不作为执行时钟采样，避免导入事件的null时钟造成错误累计。

实际历史记录Q3修正后为108865.62ms，页面显示1.81分钟。切换问题重置该问题的回放位置并停止播放；暂停中的切换直接定位新问题起点。

历史回放的观测坐标轴使用已录制完整问题范围，播放期间刻度固定；实时运行轴按1/2/5刻度扩展，避免末端数字不断跳变。条形仍按精确时间逐帧移动。可见运行耗时和回放位置最多每500ms刷新，动态文本去除毫秒小数/秒小数；暂停或完成立即显示精确耗时，详情和无障碍标签保留精确值。

问题范围与文字节流验证结果：20项计时/布局单元测试、51项桌面/390px/320px完整浏览器回归通过，类型检查及生产构建通过。新增逐帧探针确认448ms内可见耗时最多两种文本、条形至少24种宽度、历史刻度保持同一组数字，暂停时立即恢复精确值。已在真实Chrome会话确认当前Q3总时长显示1.81分钟。

## Call graph 数字刷新补齐

Call graph 原先仍直接逐帧格式化 durationMs，回归探针在448ms内记录到27种文字。节点耗时现复用 useTimeLabels：实时连接或播放中最多每500ms更新文本，暂停和调用完成立即恢复精确值，悬浮提示保留原始精度；开始时间戳及播放时钟不受影响。桌面、390px、320px的测试检查文字变化次数、播放位置持续推进、暂停460ms和完成970ms的精确展示。
