# 试用反馈优化方案与执行记录

日期：2026-10-04。依据用户试用反馈和两张截图。先记录方案，再逐项实现；保留已有事件日志、历史回放与真实调用关系。

## 1. 纵向缩进的调用树

问题：问题、Turn、调用三个层级分层，但同级持续向右扩展，多个问题/轮次造成超宽画布。

方案：采用纵向深度优先顺序：Question → Turn → Calls → Next Turn → Next Question。各层固定缩进，同级只增加 Y 坐标，宽度不随问题或 Turn 数量增长。为问题和轮次提供就地折叠；调用关系可作为次要连接线保留，不能将纵向顺序误表达为工具串行执行。当前选中节点高亮、可聚焦，图节点持续保留 React Flow measured 尺寸。移动端缩进更紧凑，保持直接选择调用的入口。

验收：多问题、20+ Turn、重名及并发工具 fixture；画布横向范围有界、顺序清楚，折叠/筛选/刷新无节点隐藏回归。

## 2. 有辨识度且稳定的名称

问题：多个“用户问题”“模型响应”“read”无法区分，Turn 1 在不同问题中重复。

方案：使用稳定层级编号 Q1、Q1.T2、Q1.T2.C3，再附用户输入摘要、模型名称/响应序号或工具名称。提问摘要优先读取 Pi 消息 text block，兼容已有数据从归档 payload 中补充；不把正文数组视为无内容。工具可在已有输入中提取文件路径、搜索词或命令摘要，默认截短，完整内容仍在详情。名称统一供导航、图、时间轴、详情与搜索使用，筛选后不重新编号。

验收：重复文本与同名工具仍唯一可辨；旧数据仍可浏览；回放名称不读取游标之后才出现的内容。

## 3. 每个问题独立计时，同时保留总览

问题：跨问题的长空闲间隔压缩具体调用，难以回答一次提问中各 Turn/工具耗时。

方案：默认按问题分组时间轴，每组自己的 0 点和比例尺，展示问题与 Turn 的区间耗时、各调用区间和并发关系。可切换会话总览，显示全局起止时间、总跨度和各问题位置；明确总跨度包含问题之间的间隔，不等于调用耗时相加。相同单调时钟域才计算实测区间，不混用不同 epoch 时钟；历史导入未知时长保持未知。回放计时固定在当前前缀。

验收：两个相隔一小时的问题，第二问中的毫秒/秒级工具仍清楚；并发工具不累加成墙钟耗时；跨时钟和未知时间不伪造准确值。

## 4. 自适应时间单位与绝对时间戳

统一使用时长格式化工具：不足 1 秒可显示 ms，60 秒以下为 s，60 分钟以下为 min，以上为 h（中文分别为毫秒/秒/分钟/小时）。显示适当精度并避免阈值处四舍五入形成错误单位。节点、时间轴提示、详情使用一致规则。

绝对时间使用本地时区格式化，详情提供明确起止日期、时刻和时区；悬浮可查看完整时间。未知端点明确显示未记录，不能用归档时间代替执行时间。

## 5. 英文默认、可切换中文

界面默认 English，提供 EN / 中文选择并在本地保存偏好。覆盖导航、状态、阶段、回放、详情、空态、连接错误、搜索和无障碍标签；真实提问、工具名与输出内容不自动翻译。更新文档，README 默认英文并提供中文版链接。

验收：首次加载为英文；切换中文后刷新保留；已有中文采集泛称由显示层标准化，原始内容保持不变。

## 执行结果（2026-10-05，v0.2.0）

- 图布局改为固定宽度、深度优先纵向排列；24 个 Turn、72 个调用共 98 个节点的 X 坐标范围不超过 72px（手机为 36px），增多调用只增加高度。保留问题/轮次折叠、原始调用关系，滚轮纵向浏览；手动聚焦在小屏同时滚动到画布。工具栏单独占一行，不覆盖节点。
- `display-model.ts` 统一问题、Turn、调用名称；从完整回放前缀生成编号，再应用分支/问题筛选。Pi text block 提问可以直接生成摘要，旧记录的归档输入也可补充摘要。相同 `read` 有独立 C 序号并显示路径。
- `timing.ts` 统一单位、绝对时间、同 clock 边界计算与比例尺。问题优先 input.applied → run.settled、Turn 优先 turn.started → turn.ended；缺少边界时明确标记“已观测调用区间”，不伪造完整执行耗时。Turn 标题和耗时显示在对应时间条前，折叠不改变问题起点与横轴范围。
- 默认英文，Header 提供语言选择、GitHub 与 Documentation。偏好保存在浏览器中。搜索跨问题/分支，但只访问当前回放前缀；点击结果切换到所属问题并展开调用。输入摘要按会话/不可变 payload ID 缓存，最多 256 项、3 个并发请求，单项只读首个 64 KiB 页面；不是输出全文检索。
- 连续 Pi 请求先清除旧问题/Turn 归属；只有确认没有新用户消息的 continuation 才复用前一问题。继续执行会清除旧结束时间，避免正在运行的调用沿用上一轮耗时。无 runId 的 settled 仅关闭明确关联的问题。
- 更新英文 README 和中文版；构建版本为 0.2.0。源代码、说明与截图均在独立项目内，未修改 pi-learn。
